# Commit: 0014149e9fb7e1a0d2fb6ba47d4116849136b35c
Message: init
Date: 2024-08-31
Author: MarcinKorcz101

Initial project setup with complete Among Us-style game framework for LLM agents.

## Core Game Engine (game_engine.py, 321 lines)
- GameEngine class managing full game loop: action phase → discussion → voting
- Action priority system: REPORT > KILL > DO_ACTION > MOVE > WAIT
- Player visibility system: players see actions of others in same room
- State tracking: locations, cooldowns, dead bodies, task completion
- Methods: main_game_loop(), update_game_state(), go_to_discussion(), go_to_voting()

## LLM Agents (3 files, ~300 lines total)
- AdventureAgent: prompts LLM to choose actions during task phase, parses action responses
- DiscussionAgent: prompts LLM to generate discussion messages, handles conversation context
- VotingAgent: prompts LLM to vote on who to banish

## Game Models (game_models.py, 136 lines)
- GameLocation enum: all Among Us map locations (Cafeteria, Storage, Electrical, etc.)
- PlayerState enum: ALIVE, DEAD, DEAD_REPORTED, BANISHED
- GamePhase enum: ACTION_PHASE, DISCUSS, VOTE
- GameActionType enum: WAIT, MOVE, DO_ACTION, KILL, REPORT, VOTE
- GameAction class with input/output/spectator story generation
- ShortTask and LongTask classes

## Player Model (player.py, 270 lines)  
- Player class with role (crewmate/impostor), location, tasks, history
- Integration with LLM agents for prompting
- History tracking for each turn (actions, seen events, locations)

## Utility Functions (utils.py, 54 lines)
- Task generation: 24 short tasks and 9 long tasks across map locations
- Random task assignment to players

## Test Scripts
- test_ai_action_phase_crewmate.py: benchmarks task completion with GPT-4o/GPT-4o-mini
- test_ai_whole_game.py: runs full games with 5 AI players (4 crewmates + 1 impostor)

## Config (consts.py)
- Game parameters: NUM_PLAYERS, NUM_IMPOSTORS, NUM_ROUNDS, IMPOSTOR_COOLDOWN
- Task counts: NUM_SHORT_TASKS, NUM_LONG_TASKS
- Discussion settings: NUM_CHATS
